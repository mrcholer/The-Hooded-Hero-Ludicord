## Ludicord adaptation

**[mrcholer](https://github.com/mrcholer)** maintains the Discord Activity adaptation in [The-Hooded-Hero-Ludicord](https://github.com/mrcholer/The-Hooded-Hero-Ludicord).

Adaptation work includes Ludicord routing/authentication, React menus and party UI, authenticated WebSockets, race loading/reconnect/results, shared AZERTY/WASD/arrow input, browser controller support, lifecycle fixes, audio conversion, documentation and deployment configuration. These additions do not transfer authorship of the original game or imply the original creator's endorsement.
